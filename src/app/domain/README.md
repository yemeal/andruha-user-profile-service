# Доменный слой сервиса профилей пользователей (`user-profile-service`)

Доменный слой представляет собой изолированное ядро сервиса, реализованное по принципам **Domain-Driven Design (DDD)**. Слой не зависит от внешних фреймворков (FastAPI), баз данных (PostgreSQL/SQLAlchemy) и брокеров сообщений (Kafka). 

Сервис выступает **Единым источником правды (Single Source of Truth, SSOT)** для публичных профилей и пользовательских настроек.

---

## 1. Базовые абстракции (`app.domain.base`)

* **`DomainModel`** — корневая модель предметной области на базе Pydantic V2. Обеспечивает строгую валидацию инвариантов при любом присваивании (`validate_assignment=True`) и прозрачную работу с псевдонимами полей (`populate_by_name=True`).
* **`Entity`** — неизменяемая базовая сущность с уникальным идентификатором `UUIDv7` (сохраняющим хронологический порядок) и меткой времени создания `created_at`.
* **`MutableEntity`** — сущность с поддержкой изменения состояния. Инкапсулирует опциональную дату обновления `updated_at`, инвариант хронологии (`created_at < updated_at`) и метод фиксации изменений `mark_updated(now)`.
* **`VersionedMutableEntity`** — сущность с поддержкой оптимистической блокировки (**Optimistic Concurrency Control, OCC**). Гарантирует целостность при конкурентных запросах через инкремент версии в `mark_updated(now)`.

---

## 2. Агрегаты (`app.domain.aggregates`)

* **`UserProfile`** — корень агрегата публичного профиля пользователя:
  * **Роль в системе:** Управление представлением пользователя в мессенджере (поиск, чаты, карточка профиля).
  * **Бизнес-ответственность:** Инкапсулирует переходы жизненного цикла (`deactivate`, `block`, `activate`), управление аватаром в объектном хранилище (`update_avatar`), административную верификацию (`verify`, `unverify`) и мутацию данных профиля (`update_profile`).
* **`UserSettings`** — корень агрегата персональных настроек:
  * **Роль в системе:** Хранение пользовательских предпочтений интерфейса и прав доступа к персональным данным.
  * **Бизнес-ответственность:** Управление параметрами отображения, часовым поясом, локализацией и сбросом настроек к дефолтным значениям (`reset_to_defaults`).

---

## 3. Объекты-значения (`app.domain.value_objects`)

Каждый Value Object является самовалидирующимся и защищает систему от некорректных состояний:

* **`Username`** — публичный уникальный никнейм (`[a-z0-9_]{3,32}`). Защищает систему от коллизий и коллизий с системными служебными адресами (чёрный список зарезервированных имён `admin`, `support`, `bot` и др.).
* **`DisplayName`** — публичное имя пользователя (1..64 символа). Защищает UI от графических искажений и злоупотреблений за счёт блокировки эмодзи с высокопроизводительной C-оптимизацией.
* **`Bio`** — текстовое описание профиля (до 255 символов). Защищает карточки контактов от некорректных многострочных вставок.
* **`UserProfileStatus`** — статус учётной записи (`ACTIVE`, `DISABLED`, `BLOCKED`). Служит триггером для политик авторизации и поиска.
* **`Theme`** — тема оформления интерфейса (`LIGHT`, `DARK`, `SYSTEM`).
* **`Locale`** — язык интерфейса пользователя (`RU`, `EN`, `KK`, `UZ`).
* **`Timezone`** — часовой пояс пользователя (по базе IANA). Обеспечивает корректный рендеринг времени сообщений и событий.
* **`PrivacyScope` & `PrivacySettings`** — неизменяемый композитный объект настроек приватности. Определяет видимость аватара, биографии и доступность профиля в глобальном поиске.

---

## 4. Доменные исключения (`app.domain.exceptions`)

* **`DomainError`** — базовый класс всех ожидаемых ошибок предметной области.
* **`UserProfileError`** и его потомки (`InvalidDisplayNameError`, `ReservedUsernameError`, `InvalidProfileStatusError`, `UsernameAlreadyTakenError`, `UserProfileNotFoundError`, `ProfileVersionMismatchError`) — ошибки, специфичные для профиля.
* **`UserSettingsError`** и его потомки (`InvalidThemeError`, `InvalidLocaleError`, `InvalidTimezoneError`, `InvalidPrivacyScopeError`, `UserSettingsNotFoundError`) — ошибки настроек пользователя.

---

## 5. Служба времени (`app.domain.clock`)

* **`utc_now()`** — изолированная фабрика времени в стандарте UTC, предотвращающая использование платформозависимого локального времени.
